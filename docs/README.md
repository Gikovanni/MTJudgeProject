# Documentação

O roadmap e o PDF das regras abrangentes, localizados na raiz do repositório, são as fontes iniciais de requisitos e de dados.

Quando o processamento da base de regras for implementado, os artefatos gerados deverão ficar fora do código-fonte da interface e manter metadados de rastreabilidade: regra, seção, página, documento e versão.
